# 03 — Pandas for Data Science

A practical, reproducible Pandas learning module using **synthetic retail transactions**. Covers data inspection, validation, missing values, filtering, feature engineering, groupby, joins, pivot tables, dates, and visualization.

## Contents
- [Study Notes](Study_Notes.md)
- [Executable Jupyter Notebook](Examples.ipynb)
- [Practice Questions](Practice_Questions.md)
- [Worked Solutions](Solutions.md)
- [Sample Orders](sample_orders.csv) and [Sample Customers](sample_customers.csv)

## Quick start
```bash
pip install -r requirements.txt
jupyter notebook Examples.ipynb
```
Run the notebook from this folder. In Google Colab, upload **both CSV files** to the session before running the notebook. The notebook exports `region_sales_summary.csv`.
