# Module 02: NumPy for Data Science

A beginner-to-intermediate NumPy learning module with **original notes**, a **runnable notebook**, **12 practice questions**, and **worked solutions**. Uses synthetic data only.

## Files
- `Study_Notes.md` — concepts, syntax, examples, pitfalls, references
- `Examples.ipynb` — executable demonstrations and a mini transaction analysis
- `Practice_Questions.md` — 12 questions
- `Solutions.md` — worked answers
- `requirements.txt` — dependencies

## Run locally
```bash
python -m pip install -r requirements.txt
jupyter notebook Examples.ipynb
```
Or open `Examples.ipynb` in Google Colab and run all cells. Try exercises before viewing solutions.

**Topics:** arrays, indexing, slicing, axes, broadcasting, statistics, missing values, random sampling, and linear algebra.
