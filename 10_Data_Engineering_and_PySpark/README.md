# Module 10 — Data Engineering and PySpark

**Case study:** ETL pipeline for retail orders.

## Files
- `Study_Notes.md`: explanations and caveats
- `Examples.ipynb`: runnable notebook
- `Practice_Questions.md` and `Solutions.md`: 18 tasks and reference approaches
- `data/`: synthetic customer and retail orders CSVs (not real personal data)
- `requirements.txt`: Python dependencies

## Run
1. Create a Python 3.10+ environment and run `pip install -r requirements.txt`.
2. Open `Examples.ipynb` in Jupyter **from this module directory**; run all cells.
3. For Colab, upload the notebook and both CSVs and adjust the path to `customers_synthetic.csv` / `orders_synthetic.csv` if necessary.
4. Review results, attempt exercises, then check worked solutions.

**Important:** Generated data are synthetic. This is an educational case study, not production evidence.
