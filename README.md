# Python For Data Science

> **Learning repository** — original, introductory exercises for an MS Data Science & Analytics portfolio. Not a finished production project.

## Goal
Python fundamentals, NumPy, Pandas, and exploratory analysis.

## Contents
- `01_python_basics.py` — runnable educational example
- `02_pandas_eda.py` — runnable educational example

## Run
Use Python 3.10+ and install dependencies from `requirements.txt` if present. Run each Python script using `python filename.py`. SQL examples are SQLite-compatible. Spark requires Java and PySpark.
